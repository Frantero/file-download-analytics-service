# Сервис скачивания и анализа файлов

Веб-сервис на Python (FastAPI), выполняющий автоматический сбор каталога текстовых файлов через внешнее API, сохранение их в PostgreSQL и проведение статистического анализа содержимого (подсчет частоты символов-цифр).

Проект разработан в рамках выполнения тестового задания.

---

## Технологический стек

- **Backend:** Python 3.11+, FastAPI, Pydantic v2
- **Database & ORM:** PostgreSQL, SQLAlchemy 2.0 (AsyncIO), `asyncpg`
- **HTTP Client:** `httpx` (асинхронные запросы)
- **Frontend / UI:** Jinja2, HTML5/JS (Vanilla JS + Fetch API), Bootstrap 5
- **Infrastructure:** Docker, Docker Compose

---

## Основные возможности и особенности реализации

1. **Устойчивость к ограничению запросов (Rate Limiting):**
   - Реализована обработка ошибок `429 Too Many Requests` с автоматическим чтением заголовка `Retry-After` и задержкой повторных вызовов.
   - Учтено ограничение API: файлы запрашиваются пачками (батчами) **не более 3 штук** за один POST-запрос.

2. **Асинхронная обработка и фоновые задачи:**
   - Скачивание файлов запускается в фоновом режиме через `BackgroundTasks`, не блокируя веб-интерфейс.
   - Распаковка ZIP-архивов выполняется «на лету» в оперативной памяти (`io.BytesIO` + `zipfile`) без промежуточной записи на диск.

3. **Веб-интерфейс (UI):**
   - **Мониторинг скачивания:** Показывает статус выполнения, время старта процесса по новосибирскому времени (`Asia/Novosibirsk`, UTC+7) и интерактивный Progress Bar (*«скачано M из N»*).
   - **Таблица файлов:** Поддержка постраничной навигации (пагинация), сортировка по дате и времени скачивания.
   - **Гибкий выбор для анализа:** Возможность выбирать отдельные файлы чекбоксами, выделить файлы на странице или запустить расчёт по вообще всем файлам в БД.

4. **Аналитический модуль:**
   - Подсчёт частоты встречаемости каждой цифры (от `0` до `9`) как суммарно для всех выбранных файлов, так и с детализацией по каждому файлу отдельно.

## 📁 Структура проекта

```text
.
├── main.py              # Точка входа FastAPI, HTTP-эндпоинты и инициализация UI
├── api_client.py        # Клиент для работы с внешним API и фоновый воркер скачивания
├── analytics.py         # Модуль подсчета статистики цифр (Collections / Counter)
├── db.py                # Конфигурация SQLAlchemy AsyncEngine и описание моделей БД
├── config.py            # Настройки приложения и чтение переменных окружения (.env)
├── templates/
│   └── index.html       # Шаблон интерфейса на Jinja2 + Bootstrap 5
├── docker-compose.yml   # Конфигурация запуска сервиса и СУБД PostgreSQL
├── requirements.txt     # Зависимости проекта
└── README.md            # Документация проекта
```

## Запуск проекта
Если вы хотите запустить приложение локально, а в Docker поднять только базу данных:

```bash
# 1. Cоздаем .env
cp .env.example .env

# 2. Запускаем только контейнер с БД
docker-compose up -d

# 3. Создаем и активируем виртуальное окружение
python -m venv venv
source venv/bin/activate  

# 4. Устанавливаем зависимости
pip install -r requirements.txt

# 5. Запускаем FastAPI-сервер
python main.py
```
